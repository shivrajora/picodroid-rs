# Completed: 8 MB of PSRAM on the RP2350B: what it would take, and what it would buy

Items closed out of [psram-rp2350b-2026-09.md](../designs/psram-rp2350b-2026-09.md), moved here on 2026-09-28 so the
original lists only open work. Text is as it stood when moved; ids keep their meaning.

## Stages, if it is built

1. Bring PSRAM up at boot and prove it: a power-on test that writes and reads
   back a pattern across all 8 MB, reported through `pdb sysmon`.
2. Add the `PSRAM` linker region and the `psram_kb` MCU key.
3. Audit every `with_xip_disabled!` site for PSRAM reachability, and state the
   rule in the porting guide beside the existing flash-write rule.
4. Move the LVGL pool behind a board.toml opt-in, and measure the render
   throughput cost on the bench before making it a default anywhere.
