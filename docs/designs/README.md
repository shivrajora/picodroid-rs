# Designs and roadmaps

Design documents and roadmaps. Most of them describe work that is **already built** — they
explain the shape of the code, they are not plans to re-execute. The status line under each
title says which.

**The index for this folder, with the status and a one-line summary of every doc, is one
level up: [`../README.md`](../README.md).** It also routes by subsystem ("working on
networking → read these, in this order") and covers the audits and bug records alongside
these designs.

Two conventions worth knowing before you read anything here:

- **Amendments at the bottom override the body.** These docs were executed while reality
  diverged, and the amendment section records the divergence.
- **Numbers are tied to a commit.** Re-measure before relying on one from a different tree.
