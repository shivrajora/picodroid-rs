# One C function per line; `build_support::hot_ram::retarget` moves each
# from `.text.<fn>` to `.data.hot.<fn>` in libfreertos.a, so it executes from
# SRAM on a board with `hot_ram_kb` in its board.toml. Chosen from a
# DWT-PCSR profile of claudeusage page turns on pico_display2_w
# (2026-09-26) by samples per byte, up to a 6 KB budget (the critical sections, tick, context switch, queues and heap_4 — 9 % of the busy samples); how to re-derive it is in
# docs/designs/sram-hotpath-2026-09.md §3 and Appendix B. A name the archive
# no longer defines (after an LVGL or kernel update) is silently a no-op, so
