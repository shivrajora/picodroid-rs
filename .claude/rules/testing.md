# Testing

- **Unit tests:** `./scripts/test.sh` (the workspace on the host, both shrink modes; bare `cargo test` fails with "can't find crate for `std`"). Run it when you changed something its tests pin: a dispatch arm, a class table, a wire format, a guard count. CI runs it on every push.
- **The sim smoke:** `./scripts/sim.sh --app helloworld` after a change under `crates/`, `platforms/`, `sdk/`, `system-apps/`. A loop-forever app needs `timeout -k 2 5 ./scripts/sim.sh --apk build/apks/X.papk > log 2>&1 < /dev/null` (build the APK first so Gradle is not inside the timeout), then grep the file: a killed sim's stdout dies with it. Clean up orphans with `pkill -x picodroid` scoped to your tree.
- **Rows, not one-offs:** a behaviour worth checking becomes a `scripts/hil-tests.conf` row (`app|category|timeout|pattern;pattern[|board]`; no `|` inside a pattern) driven by a `qa_*` or example app, with `examples/<app>/test.ctrl` for input (`wait <regex>`, `sleep <s>`, control verbs). `scripts/check-hil-conf.sh` fails on a row whose app or tag no longer exists. `./scripts/sim-run.sh --app X --no-pull --no-email` runs one row; the nightly runs them all in both shrink modes and on every bench board.
- **Which board for a sim row:** `testbench_rp2350` has no buttons (`press` / `input keyevent` no-op there); key-driven rows pin `pico_display2_w` or `pico_enviro_mon` in the fifth column. `input swipe` raises a real gesture since 2026-09-28.
- **Captures:** `./scripts/sim-shot.sh <out.png> <settle-s> <sim.sh args> -- <control lines>` (needs Xvfb, xdotool, scrot). The sim prints `heap: peak` only when the app ends on its own, so end a heap comparison with `input back`. A 2 s snackbar is gone at capture time; shorten the gap.
- **Fuzzing:** every parser of untrusted bytes has a target under `fuzz/fuzz_targets` (`docs/fuzzing.md`); `./scripts/fuzz.sh --target X --time 60` for a minute, `--replay` for the committed inputs. A fixed finding's minimised input goes to `fuzz/regress/<target>/finding-*`, replayed by `test.sh` on stable. Harness traps: `reaches(n, n)`, duplicate keys, low-32-bit varints, an epoch of zero.
- **Opt-in monitors:** `--mem-diag` (heap census, memmon, offensive checks; `docs/memory-diagnostics.md`) and `--sched-diag` (core hogs, sleep-polling, starvation; `docs/scheduling-diagnostics.md`). `mem-diag` code compiles only on the `--full` clippy leg and a `--mem-diag` sim run: build one after touching `mem_diag.rs`, `alloc_ledger.rs` or the class-file census. A `--mem-diag` sim run ends in SIGFPE at teardown on purpose-free code; read its app output, not its exit code.
- **The sanitizer is on in `sim.sh`** (`PICODROID_HANDLE_SANITIZER=1`); a hand-run binary has it off, so export it when reproducing. An `[sim] OOM: tried 196608 B` right after a stale-handle report is the sanitizer's own backtrace capture, not the app's bug; `-l 0` lifts the heap cap to see the real backtrace.
- **Coverage:** `./scripts/coverage.sh` (unit layer, CI's `Coverage` job), `--sim` for the rows; `scripts/coverage-baseline.conf` is the per-crate floor (`--check` / `--accept`, `coverage:` trailer).
- **Sabotage-check a guard** before trusting it: plant the forbidden token (as a string literal for a text scan) and watch the guard fail, then remove it. A scan with a pinned count cannot pass empty.
- **Reading CI:** `gh run view --log-failed` is empty for this repo; `gh api repos/shivrajora/picodroid-rs/actions/jobs/<job id>/logs` (ids from `gh run view <id> --json jobs`, forced to integers with `--template '{{printf "%.0f" .id}}'`), strip ANSI with `sed 's/\x1b\[[0-9;]*m//g'`. A red run usually has several independent causes: fetch every failed job's log first.
