# The Java SDK and apps

- **Mirror `android.*` exactly.** A new class or member takes Android's name, signature and semantics (check `developer.android.com` before inventing). Divergences are documented in `website/src/content/docs/reference/compatibility-matrix.md` and recorded as `partial` in `sdk/android-parity.tsv`; an addition with no Android counterpart is marked **no Android counterpart** in the matrix and `addition` in the tsv. Breaking changes are free: migrate the in-repo apps in the same commit, no shims.
- **Apps import `picodroid.*`**, never `android.*`; the matrix explains why there is no alias layer.
- **Executor-only concurrency.** No `Handler`, `Looper`, `postDelayed`, `CountDownTimer`, `Timer`, `AsyncTask` (decision 2026-08-30). Post to the UI with `Executors.mainExecutor().execute(..)` or `View.post`; delayed and periodic work with `Executors.mainScheduledExecutor()`; clock-driven UI registers a `BroadcastReceiver` for `Intent.ACTION_TIME_TICK` instead of polling.
- **Flash is the budget.** Every compiled SDK class is embedded in every board's firmware; a new class costs its `.class` size on the RP2040 too. Prefer a native method on an existing class or a JVM builtin; check `testbench_rp2040`, and add the class to its `framework_class_excludes` when it cannot carry it. Accept the ratchet in the same commit (`size:` trailer).
- **Slot-addressed classes.** Rust reads `Intent` and the other `pub mod`s of `graphics/fields.rs` by field index: add instance fields only at the end and fix the slot test (`intent_field_slots_match_fields_rs`) in the same commit; statics and methods are free.
- **Name tables.** After the last Java edit run `./scripts/gen-api-contract.sh` (javac numbers lambdas by position; it also runs `no_original_name_literals`, which fails on a Rust string literal equal to a new member name: rename the member, not the Rust). A new SDK class also needs `touch crates/picodroid-core/build.rs` once. A class added between release cuts stays un-shrunk and reads as "pending" in the shrunk-image check; cuts happen on `main` only, when asked.
- **Upcalls resolve on the exact class.** `find_method_by_name` scans the named class's own table: a lifecycle or listener callback declared on an intermediate base class is never found, silently. Concrete classes declare the callbacks they rely on.
- **Error Prone is on.** QA apps that exercise `Integer == Integer`, `arr.equals(b)`, `x.equals(null)`, a non-literal format string or a fall-through need the documented escape (`(Object)` casts, helpers, `// fall through`); `DefaultCharset` is a warning only. A single-file `java Check.java` on the host JDK 21 settles what Java prints.
- **Formatting.** Google Java Style via `./scripts/format_java.sh format`; the PostToolUse hook reformats after every edit and **removes unused imports**, so add an import and its first use in one edit. 64 KB per class file; `ListView` for more than 32 clickable rows.
- **A UI claim needs a capture.** `./scripts/sim-shot.sh out.png 3 --app X -- "input tap 160 120"`; read the `[layout]` line's numbers (a content root at LVGL's default 160×160 still says `fit ok`). `setSize(MATCH_PARENT, MATCH_PARENT)` sizes a content root, `setLayoutParams` does not. Faces are bitmaps: `setTextSize` snaps to a compiled size; no `—` / `…` glyphs.
- **Documentation goes to the website.** `website/src/content/docs/api/*.md` for the surface, `reference/compatibility-matrix.md` for the divergence, `examples.md` for a new app; `docs/` is for the reasoning.
