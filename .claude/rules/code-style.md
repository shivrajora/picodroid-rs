# Rust and C in the firmware

- **No panics in firmware** (CLAUDE.md golden rule 3). No `unwrap()`, `expect()`, `panic!`, `unreachable!`, `todo!`, `unimplemented!` in non-test code of `crates/*` and `platforms/*`. Return the crate's error type with `?`, `ok_or(..)?`, `let .. else { return Err(..) }`; `unwrap_or*` only a fallback that cannot corrupt state. Indices and sizes from a PAPK, a pdb frame, the network or a class file use `get()`, `checked_*` / `saturating_*`, and a cap before any allocation. The leaf crates deny the lints; the others ratchet down (`scripts/panic-baseline.conf`).
- **Allocation is fallible.** The device heap is small and shared; an infallible `Vec::push` that grows under a full heap resets the board. Reserve fallibly (`try_reserve`), throw `OutOfMemoryError` from the JVM, fail soft in LVGL's pool (`lv_realloc` returns NULL; only the malloc assert spins forever, with no log line).
- **`unsafe` is documented and ratcheted.** Every `unsafe {` carries `// SAFETY:` on its line or the comment run above it (the word must be on the last comment line); `clippy::undocumented_unsafe_blocks` is denied crate-wide, and `scripts/unsafe-baseline.conf` only goes down. Reach for a shared primitive (`util/`, a HAL or RTOS seam method) before writing a new block. `static mut` counts separately; own a `Box<[u8]>` in a test mock instead of `&'static mut`.
- **Seams, not guesses.** Shared code asks the platform through `pd_rtos` / the HAL traits / `PlatformHooks`; it never names a FreeRTOS symbol (the seam guard) and never writes `not(feature = "family-rp")` (sim builds keep `family-rp` active; spell `feature = "sim"`). A kernel call has three implementors: `platforms/rp/src/glue.rs`, `hal/sim/platform.rs` and `test_platform.rs`.
- **No `cfg(debug_assertions)` on device.** `build-lib.sh` turns debug assertions off in both device profiles; the only debug-vs-release marker is the `line-numbers` feature. Gate diagnostics on an explicit cfg or feature and check the symbol with `nm` before trusting it.
- **Log through the facade.** `defmt` on device, `[Tag] msg` in the sim; never log inside an allocator or under the heap lock (it wedges the SMP kernel before RTT attaches).
- **Names go through the generated constants.** A dispatch arm matches `(ch::picodroid_view_View, mh::setText)`; a table row or an allocation spells a class or member through `c::` / `m::`, never a string literal (`no_original_name_literals` refuses it: the literal would stop matching under `--shrink`). New names first get a row in `sdk/class-names.tsv` / `member-names.tsv` via `scripts/gen-api-contract.sh`.
- **Numbers that load-bear get an assertion.** A C struct size the Rust side models is pinned with `_Static_assert` in a file the firmware compiles; an LVGL config switch is pinned explicitly in `lv_conf.h` with the reason (the non-Kconfig defaults are the permissive ones).
- **Spins are ledgered.** A busy-wait is `spin_until!` or carries a `spin-ok:` / `spin-todo:` marker that names a finding; `platforms/rp/src/spin_guard.rs` pins the count.
- **Style.** `cargo fmt` (the PostToolUse hook runs it after every edit); clippy `--deny=warnings` on CI's pinned toolchain (`RUST_TOOLCHAIN` in `ci_checks.yml`); bare `cargo clippy` / `cargo test` fail in this virtual workspace, use `./scripts/pre-commit` and `./scripts/test.sh`. Comments explain *why*. GPL-3.0-only SPDX header on new source files. Match the surrounding code.
