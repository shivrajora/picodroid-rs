# crates/picodroid-core

The family-neutral framework (L4): native dispatch, lifecycle, graphics on LVGL, networking, the simulator's HAL. Family code lives in `platforms/rp/`; the same relative path may never exist under both `src` trees.

- **Test:** `./scripts/test.sh`; the sim smoke `./scripts/sim.sh --app helloworld`; clippy legs via `./scripts/pre-commit` (this crate is linted through `-p picodroid` for every board and the sim). Panic sites here are ratcheted (`scripts/panic-baseline.conf`: 40 left on 2026-10-20); the goal is zero, then the deny attribute.
- **Adding a native** (`CONTRIBUTING.md` has the long form): implementation under `native_handler/`, a class in `PICODROID_NATIVE_CLASSES` (`class_registry.rs`), a `(class, method, descriptor)` row in `method_tables.rs` (the bidirectional test prints ready-to-paste rows), names through `ch::` / `mh::` hashes in arms and `c::` / `m::` consts in tables, descriptors from `sdk/descriptors.tsv`. New names first: `./scripts/gen-api-contract.sh`.
- **Deferred callbacks** reach Java through the append-only `dispatch_sites.rs` table; synchronous ones through `NativeContext::upcall` (`invoke_java`). `Activity` lifecycle is dispatched concrete-class-first then `picodroid/app/Activity`, nothing in between.
- **Widgets own their Java objects through the handle table** (generation-tagged; a stale handle is a no-op, the sim's sanitizer reports it). Listeners are fields of the view, bound at `set*Listener`; a shown `AlertDialog` / `Snackbar` is held until dismissed. `pd_canvas` owns LVGL user data; a hand-rolled `static mut` table in a widget is suspect until its delete hook is found.
- **LVGL's pool is a second heap** (`lv=` on the memmon line): 48 KB, full means a silent `while(1)` in the UI task. Cap anything new that allocates there; `PD_CANVAS_MAX_BYTES` is 2048 per view.
- **The sim is the device's twin**: every divergence is a simulator bug (`docs/parity-audit.md`). Blocking host calls inside a task starve lower-priority tasks (the POSIX port switches only at FreeRTOS blocking points); give such a task the JVM tier under `cfg(any(feature = "sim", test))`. Host crypto needs the soft backends (`.cargo/config.toml`); nothing boxed may want more than 8-byte alignment.
- **Networking** goes through `NetLink` / `ConnectivityManager` and `throw_net_exception`; a blocking read with a timeout tracks an explicit deadline across EINTR. TLS: `pd-tls` (compiled-in roots, heap-resident session, clock required).
- **Build budget:** a screen's build must stay under 250 ms (`docs/designs/ui-build-budget-2026-10.md`); the one-native inflate is the fast path. Text faces are bitmaps compiled per board (`text_sizes`).
- `mem-diag` and `sched-diag` code compiles only on the `--full` clippy legs and an opt-in sim run: check one after touching `mem_diag.rs`, `alloc_ledger.rs`, `hal/sim/boot_budget.rs`.
