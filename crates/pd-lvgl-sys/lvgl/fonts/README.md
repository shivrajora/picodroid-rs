# Generated faces

The Montserrat faces `TextView.setTextSize` can snap to, one C file per pixel
size, generated by `scripts/gen-fonts.sh` and committed. Do not edit them: run
the script.

Source: `third_party/lvgl/scripts/generators/built_in_font/Montserrat-Medium.ttf`,
the TTF LVGL builds its own `lv_font_montserrat_*` from (Montserrat, SIL Open
Font License 1.1, © The Montserrat Project Authors). Each face holds ASCII
`0x20-0x7F` plus `°` (U+00B0) and `•` (U+2022) — LVGL's stock glyph set minus
its FontAwesome symbols, which only the 14 px theme face needs — at 4 bits per
pixel, uncompressed, with kerning.

A board compiles only the sizes its MCU or board toml lists in `text_sizes`;
`pd_fonts.c` next door assembles the table the runtime reads. See
`scripts/gen-fonts.sh` for the exact `lv_font_conv` invocation and the reasons
behind the flags.
